<h2>⚡ What This Actually Does</h2>

<ul>
  <li>📊 Shows all classrooms in one dashboard</li>
  <li>🟢🔴 Live <b>Vacant / Occupied</b> status</li>
  <li>👨‍🏫 CRs & Teachers can update room status</li>
  <li>🔄 Updates instantly for everyone</li>
</ul>
