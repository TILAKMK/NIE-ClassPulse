<h1 align="center">🚀 NIE ClassPulse</h1>

<p align="center">
⚡ Real-Time Classroom Availability System <br>
<b>Stop wandering. Start knowing.</b>
</p>

<hr>

<h2>🧠 The Idea</h2>
<p>
Finding an empty classroom in college is frustrating.
Students waste time searching, interrupt classes, and lose productivity.
</p>
<p><b>👉 ClassPulse solves this with live classroom tracking.</b></p>

<hr>

<h2>✨ What It Does</h2>
<ul>
  <li>🔹 Displays all classrooms in a single dashboard</li>
  <li>🔹 Shows <b>Occupied / Vacant</b> status in real-time</li>
  <li>🔹 Allows CRs & Teachers to update room status</li>
  <li>🔹 Updates instantly across all users</li>
</ul>

<hr>

<h2>🧩 How It Works</h2>
<ol>
  <li>Dashboard loads data from Supabase</li>
  <li>Rooms displayed as cards</li>
  <li>Realtime listener tracks changes</li>
  <li>Updates reflect instantly for all users</li>
</ol>
